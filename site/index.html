How to Install the Browser Extension

Add WriteAssist to any Chromium browser in less than a minute:

1
Download & Extract

Download writeassist-extension.zip from above and extract it into a folder on your computer.

2
Open Extensions Page

In Chrome, Edge, or Brave, open chrome://extensions and switch on Developer mode (top right).

3
Load Unpacked

Click Load unpacked, select the extracted extension folder, and pin the WriteAssist icon!

Frequently Asked Questions

Is WriteAssist really free?

Yes, 100%. Grammar checking uses the free public LanguageTool API with zero API keys required. AI rewrites can use Google's free Gemini API key or your own OpenRouter credentials.

Can I use both the desktop app and the extension together?

Yes! The desktop app runs as a local background daemon that provides a standalone desktop writing workspace and can serve requests locally.

How is my text protected?

Your text is never sold or used to train public models. You can also self-host LanguageTool and point WriteAssist to your private instance in Settings.
